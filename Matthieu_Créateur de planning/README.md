# Créateur de planning

Le but de ce projet est de pouvoir ajouter notre planning fixe et de voir ou rajouter nos tâches. Voir autres projets.

MVP :
1. Demander information importantes : demander heure de sommeil, quel activité reviennent chaque semaine et créer un planning fixe;
2. Faire une interface graphique de ce planning;

VF :
1. Demander information importantes : demander heure de sommeil, quel cours et hobby reviennent chaque semaine et créer un planning fixe;
2. Demander importance de chaque activité (quels est le plus important l'un envers l'autre)
3. Faire une interface graphique de ce planning;
